How to use this book

Complete each part after that block of the topic. Each section mixes quick recall with explanation, calculations and practical thinking. Use Print for paper copies, or type directly into the boxes. The final quiz is a 20-question mixed check.

Suggested target: 70%+ on the multiple-choice checks before moving on; then correct written answers using teacher feedback.
